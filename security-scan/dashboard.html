② 検知カバレッジ マトリクス Detection coverage

③ 予防コントロール Preventive controls

検知の前段で効く固定策。優先度順。

  • 送信ドメイン allowlist — サーバ系からの LLM/メッセージングは既定遮断。
  • コンテナ admission control — 特権cap・host net・未署名/未知イメージを禁止。
  • 攻撃面最小化 — 管理画面の隔離、DB/サービスをネット直結にしない（netcheck の RISKY ポート群）。
  • 決済・機微ページの CSP — skimmer/カード窃取コード注入の防止。
  • LLM 利用の監査・ガバナンス — 安全機構の除去/迂回の試行を検知・通報。

④ CVP（Cyber Verification Program）対応 Anthropic

活動をどのティアで正規化するか。詳細は cvp-readiness.md。

Defense Access
防御（SOC/IR/マルウェア解析/脆弱性検証）。個人研究者も可・審査数日。本リポの防御ツール＋解析＋検知ルールが射程。
Red Team Access
認可されたペンテスト（組織のみ・数週間）。Cairn ラボ運用はここ。隔離設計・ランブック・mock検証が統制証拠。
Specialized Access
安全重要システム（電力/通信/金融/政府網）。米政府連携が必要。

不変の一線：物理被害・大規模妨害・ランサム・安全系無効化はブロック対象。
