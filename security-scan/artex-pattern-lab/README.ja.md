# ARTEX パターンラボ(R29/R30/R31 の動作確認、唯一の最小アプリ)

Hunt.io の報道(2026-11-04、ARTEX / 韓国 7 金融機関への侵害基盤)にあった 3 つの挙動を、
**別々のアプリを 3 つ作らず、`vulnerable_app.py` という 1 つの最小アプリにまとめて**
再現し、対応する検知ルール(`detections/r29_*`・`r30_*`・`r31_*`)が、実際に効くかを
確認するラボ。`sqli-lab` と同じ位置づけ(このラボ自体の脆弱性診断ではない)。

## 対象の3挙動(1 アプリにまとめた理由)

| ルール | エンドポイント | 再現する挙動 |
|---|---|---|
| R29 | `/jndi`(脆弱)・`/jndi_safe`(修正) | JNDI ルックアップ文字列(`${jndi:ldap://...}`)を受け取り、実際に LDAP/RMI へ接続する |
| R30 | `/login` | `X-Forwarded-For` を信用し、同一アカウントへの認証試行を、送信元 IP ごとに記録する |
| R31 | `/crypto_relay`(脆弱)・`/crypto_relay_safe`(修正) | 指定されたホストへ、サーバー自身が直接中継する |

3 つとも「サーバー側のプロセスが、外部からの入力に押されて、意図しない接続・動作をする」
という同じ形の問題なので、1 本の Flask アプリにまとめても、互いの検証を妨げない。

## 安全のための制限

- 接続先は、**127.0.0.0/8 のみ**(`_host_allowed`)。本物の LDAP サーバーにも、本物の
  暗号資産取引所にも、一切接続しない。
- 模擬サーバー(ローグ LDAP 役・取引所 API 役)は、どちらも `check_detections.py` が
  その場で起動する、応答するだけの最小限のもの。

## 実行方法

```bash
pip install flask
python3 check_detections.py
```

内部で、`/etc/hosts` に、このラボ専用の 1 行(`127.0.0.9 api.testupbit.exchange.lab`)を
一時的に追加し、**終了時に必ず取り除く**(名前解決に、本物の DNS ではなく `socket.create_connection`
を使う `/crypto_relay` の挙動を、実際に再現するため)。

## 確認した結果(2026-11-06、このセッションで実行)

7 項目すべて OK:

```
OK  JNDI 脆弱版: 実際に接続した
OK  JNDI 修正版: 接続しなかった
OK  暗号資産取引所 相当 脆弱版: 実際に中継した
OK  暗号資産取引所 相当 修正版: 中継しなかった
OK  R29: JNDI 経由の新規接続イベントを検知した(脆弱版のみ記録されるはず)
OK  R30: alice(15IP)を検知、bob(3IP)は検知しない
OK  R31: 取引所相当への通信を検知した(脆弱版のみ記録されるはず)
```

## 確認できていないこと・簡略化した点(正直に)

- **本物の Sigma/Falco/Datadog エンジンでは確認していない。** `check_detections.py` の
  `detect_r29`/`detect_r30`/`detect_r31` は、各 YAML/JSON のロジックを **Python に手で
  移植したミニ判定器**であり、本物のエンジンに読み込んで動かしたものではない。移植に
  誤りがあれば、ここでの OK は、本番のルールの正しさを保証しない。
- **R29 は、宛先ポートの条件を省略している。** 本番のルールは `389/636/1099` に絞って
  いるが、このラボのローグ LDAP 役は任意のポート(13890)を使っており、`process_name`
  だけで判定している(`check_detections.py` の `detect_r29` のコメントに明記)。
- **R30/R31 は、集計(閾値)をこのスクリプト内で単純に再現しただけ。** 本番は SIEM 側の
  集計機能(5〜15分の時間窓など)を前提にしており、このラボは 1 回の実行内の件数を
  数えているだけで、時間窓は見ていない。
- `java` プロセスの挙動を、Python 製のこのラボで模擬している(`process_name` を
  手動で `"java"` と記録しているだけで、実際に Java プロセスが動いているわけではない)。
