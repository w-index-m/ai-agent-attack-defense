# AI攻撃エージェント 防御ダッシュボード — はじめての人向けガイド

対象: `security-scan/dashboard.html`。セキュリティの専門知識がなくても、何が見られて
何をすればいいかが分かるように書いたもの。詳しい技術的な中身は
[`security-summary.ja.md`](security-summary.ja.md)（まとめ）や
[`defense-playbook.ja.md`](defense-playbook.ja.md)（防御プレイブック）を参照。

## これは何？

**ブラウザで開くだけの1枚のページ**です。インストールも、サーバーへの接続も、アカウント
登録も要りません。

```bash
# ブラウザで直接開くだけ
open security-scan/dashboard.html   # Mac
start security-scan\dashboard.html  # Windows
```

中身は、**「AIを使った新しいタイプのサイバー攻撃」が実際にどう動くか**を整理し、
**「自社は何を守ればいいか」**を一覧にしたものです。外部と通信しないので、社内の機密情報を
扱っていても安心して開けます。

## なぜ必要なの？（背景を1分で）

2026年に入り、**AI（ChatGPTのようなもの）に「攻撃用のツールを自分で考えて実行させる」**
という攻撃の仕方が実際に報告されるようになりました。人間のハッカーが一つ一つ手作業で
やっていたことを、AIが自動でやってしまう、というイメージです。

これまでのセキュリティ対策（ファイアウォールやパスワード管理など）がまるごと無意味に
なるわけではありませんが、**AIが「侵入口を自分で探す」「複数のAI同士で役割分担する」**
という新しい動き方をするため、見るべきポイントが少し変わります。このダッシュボードは、
その「見るべきポイント」を一覧にしたものです。

## 画面の6つのブロック、それぞれ何が分かるか

| ブロック | 平たく言うと | あなたが見てすること |
|---|---|---|
| ① 攻撃用AIエージェント マップ | 「AIを使った攻撃」にも種類がある、という一覧表 | 自社が狙われやすいタイプ（Web公開しているサービスがあるか等）をざっと眺める |
| ② 検知カバレッジ マトリクス | 「この攻撃が来たら、うちのシステムは気づけるか」の○×表 | 自社で導入しているセキュリティ製品（ログ監視など）が、どの段階の攻撃を拾えるかの目安にする |
| ③ 予防コントロール | 事前にやっておくべき対策の一覧 | 自社でまだやっていない項目がないか、チェックリストとして使う |
| ④ スキル機構とガバナンス | AIが「新しい攻撃手段を自分で作る」ことへの対処 | ここは専門的な内容。社内のAI活用ルールを決める人向け |
| ⑤ CVP対応 | Anthropic社の認定プログラムへの対応状況 | 直接自社に関係なければ読み飛ばしてよい |
| ⑥ リポジトリ資産 | このリポジトリに入っている他のツール・文書への入口 | 「もっと詳しく知りたい」「実際に確認したい」ときのリンク集 |

## 初心者・非専門家でも、具体的にできること

難しい専門知識がなくても、以下は今日からできます。

1. **①と②をざっと眺めて「自分の会社に関係ありそうな攻撃の形」を知る**
   読むだけでOK。覚える必要はありません。「へえ、こういう攻撃のされ方があるんだ」で十分です。

2. **③のチェックリストを、自社でできているか上司やIT担当に確認してもらう**
   自分で判断できなくても、「このリストにある項目、うちは大丈夫ですか？」と聞くだけで
   十分な価値があります。

3. **`netcheck`（このリポジトリの別ツール）で、自分のPCやサーバーの「開いている穴」を
   確認する**
   ブラウザの画面で操作できるツールです。詳しくは
   [`local-vuln-testing-walkthrough.ja.md`](local-vuln-testing-walkthrough.ja.md)。

4. **「分からない言葉」が出てきたら [`glossary.ja.md`](glossary.ja.md) を見る**
   FIM、CSP、WORM、egress、C2、RCE、IAMなど、1行でやさしく説明した用語集があります。

5. **「結局何が重要なの？」と思ったら [`security-summary.ja.md`](security-summary.ja.md) の
   「3. 企業として取るべき対応」の表だけ見る**
   表形式で、やるべきことと、このリポジトリのどのツールが手伝ってくれるかがまとまって
   います。

## やらなくていいこと

- 攻撃ツール（Strix、Cairn等）の**使い方を覚える必要はありません**。このリポジトリは
  防御側の視点でまとめたもので、攻撃の実行手順そのものは載せていません。
- 全ての専門用語を理解する必要はありません。分からない部分は読み飛ばして、
  チェックリスト（③）と対応表（`security-summary.ja.md`の3節）だけ押さえれば十分です。
