# md-to-github-pptx

GitHub上でコピペしたMarkdown(セッションのやり取りログ、Issue/PRの説明文、READMEの抜粋など)を、
見た目を崩さずにそのままPowerPointスライドへ変換するツール。

> このツールはリポジトリ本体の検知/防御の研究とは無関係な、汎用ユーティリティです。
> 作業ログをスライド資料化する際にコピペで書式が崩れる問題への対処として、
> このリポジトリの `tools/` に置いています。

## できること

- `#`/`##`見出しごとにスライドを自動分割
- フェンス付きコードブロック(` ``` `)を、GitHubのコードブロックに近い見た目
  (薄灰色背景・角丸・等幅フォント)のカードとして描画
- `|...|`形式のテーブルを、ヘッダー網掛け付きの本物のPowerPointテーブルとして描画
- `-`/`*`の箇条書き、`1.`の番号付きリストに対応
- `**太字**`・`` `インラインコード` ``のインライン書式に対応
- 1枚に収まらない内容(長いコードブロック・長いテーブル含む)は自動で「(続き)」スライドに分割

## 使い方

```bash
cd tools/md-to-github-pptx
npm install          # 初回のみ(pptxgenjsを導入)
node md_to_github_pptx.js 入力.md 出力.pptx ["スライドタイトル(省略可)"]
```

`入力.md`内の最初の`# 見出し`、またはタイトル引数省略時はファイル名がデッキタイトルになる。

## 制限・既知の注意点

- 対応しているMarkdownは上記のサブセットのみ(ネストしたリスト、リンク、画像、
  インデントされたコードブロックなどは非対応)。
- 1行あたりの折返し行数は日本語/英語混在テキストの文字幅をもとにした概算推定であり、
  完璧ではない。生成後は `scripts/office/soffice.py --headless --convert-to pdf` 等で
  画像化して目視確認することを推奨(詳細は本リポジトリが参照しているpptxスキルの
  QA手順を参照)。
- GitHubのMarkdownレンダリング全体(リンク色、絵文字、脚注など)を再現するものではなく、
  あくまで「コードブロック・テーブル・見出し・リストが崩れずスライド化される」ことを
  目的とした簡易ツール。
